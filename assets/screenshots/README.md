# App Screenshots

This folder contains realistic app mockups for the BAHHAR landing page.

## Files
- `home-dashboard.html` - Hero phone mockup with fishing score
- `trip-planner.html` - Trip planning wizard step 3
- `map-view.html` - Interactive map with real OpenStreetMap tiles
- `catch-log.html` - Catch logging interface

## How to Use
These HTML files render as realistic phone mockups with actual functionality and can be screenshot for use in marketing materials.

## Update Instructions
1. Open each HTML file in a browser
2. Take screenshots (recommended size: 1242x2688 for iPhone)
3. Use these images in the landing page

For now, these are embedded directly in the landing page as iframes for live demonstration.
